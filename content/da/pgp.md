## Hvornår skal du bruge denne nøgle

Brug denne PGP-nøgle til at kryptere følsomme sikkerhedsrapporter eller kommunikation til LogicNodes' sikkerhedsteam, herunder:

- **Rapporter om sikkerhedssårbarheder** (se [Politik for ansvarlig offentliggørelse](/da/ansvarlig-offentliggorelse/))
- **Underretninger om databrud**
- **Fortrolige sikkerhedsforespørgsler**
- **Følsomme sikkerhedsoplysninger fra partnere**

**Bemærk:** PGP-kryptering er valgfri. Du kan også sende ukrypteret e-mail til kontakt@logicnodes.ai til ikke-følsom kommunikation.

## Sådan bruger du denne nøgle

### 1. Importer den offentlige nøgle

**Med GPG (kommandolinje):**
```bash
# Download og importer nøglen direkte
curl https://legal.logicnodes.ai/en/pgp.txt | gpg --import

# Eller download først, derefter importer
curl https://legal.logicnodes.ai/en/pgp.txt -o logicnodes-security.asc
gpg --import logicnodes-security.asc

# Verificer fingeraftrykket
gpg --fingerprint kontakt@logicnodes.ai
```

**Med Keybase:**
```bash
keybase pgp pull kontakt@logicnodes.ai
```

**Med e-mailklienter:**
- **Thunderbird med Enigmail:** Funktioner → OpenPGP-nøglehåndtering → Importer
- **Apple Mail med GPGTools:** Åbn GPG Keychain → Importer
- **Outlook med Gpg4win:** Kleopatra → Importer certifikater

### 2. Verificer fingeraftrykket

**Verificer altid fingeraftrykket** inden du krypterer følsomme data:

**Publiceret fingeraftryk:**
`FD15 E817 5925 8403 5F53  0A4A 389B 966F 7079 41C4`

**Tjek via flere kanaler:**
- Denne side: /da/pgp
- Security.txt: /.well-known/security.txt
- Kontakt os direkte: kontakt@logicnodes.ai (vi bekræfter via signeret e-mail)

### 3. Krypter din besked

**Med GPG (kommandolinje):**
```bash
# Krypter en besked
gpg --encrypt --armor --recipient kontakt@logicnodes.ai besked.txt

# Dette opretter besked.txt.asc - send denne fil via e-mail
```

**Med e-mailklienter:**
De fleste e-mailklienter med PGP-plugin tilbyder automatisk kryptering, når du skriver en e-mail til kontakt@logicnodes.ai.

### 4. Send din krypterede besked

**E-mail til:** kontakt@logicnodes.ai
**Emne:** [SECURITY] Kort beskrivelse
**Brødtekst:** Indsæt den krypterede besked (inkl. `-----BEGIN PGP MESSAGE-----`-header)

**Eksempel:**
```
To: kontakt@logicnodes.ai
Subject: [SECURITY] SQL Injection-sårbarhedsrapport

-----BEGIN PGP MESSAGE-----

[Din krypterede besked her]

-----END PGP MESSAGE-----
```

## Verifikation af vores svar

Alle svar fra kontakt@logicnodes.ai vil være **PGP-signeret** for at verificere ægthed.

**Sådan verificerer du vores signatur:**
```bash
# Tjek signaturen på en signeret besked
gpg --verify besked.asc
```

**Forventet output:**
```
gpg: Good signature from "LogicNodes Security Team <kontakt@logicnodes.ai>"
```

**Advarsel:** Hvis du ser "BAD signature" eller et andet fingeraftryk, **må du ikke stole på beskeden**. Kontakt os via en anden kanal øjeblikkeligt.
